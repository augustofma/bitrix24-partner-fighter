# ui

Arte de interface.

- `title/`: camadas da tela inicial (fundo, logo e botão JOGAR), geradas por
  [scripts/title-art](../../scripts/title-art/README.md).
- `victory/`: camadas da tela de vitória (fundo, moldura do card, painel do resultado e botão),
  geradas por [scripts/victory-art](../../scripts/victory-art/README.md).

Veja [docs/ART_DIRECTION.md](../../docs/ART_DIRECTION.md).
